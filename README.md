# E-commerce Sales Analysis Project

## Project Overview
This project analyzes 100 recent sales transactions to uncover revenue trends, product performance, and regional sales distribution. It was developed to fulfill the Week 4 Data Visualization curriculum. As an entry-level data analyst, the goal was to build a complete pipeline that ingests raw CSV data, cleans the dataset, and outputs professional, labeled visualizations using `pandas` and `matplotlib`.

## Code Structure
- `data/`: Contains the raw dataset (`sales_data (1).csv`).
- `visualizations/`: Destination folder for generated `.png` charts.
- `report/`: Contains the final written insights document.
- `main.py`: The primary Python execution script.
- `requirements.txt`: Python package dependencies.
